# AJAX Rating Project

## Description

This web application manages a rating interface using AJAX to communicate with a PHP backend.  
It contains a simple HTML page with two buttons:

- **Rating**: to open a dynamically loaded rating form  
- **Close**: to close the form

The form and rating results are displayed without page reload thanks to AJAX.

---

## Project Contents

- `index.html`: main HTML page  
- `style.css`: CSS styles for layout and design  
- `script.js`: JavaScript script to handle AJAX requests and user interaction  
- PHP backend to receive AJAX data and process the ratings

---

## Features

- Dynamic loading of the rating form via AJAX  
- Asynchronous submission of ratings to the PHP server  
- Display of results without page reload  
- Simple and responsive interface

---

## Installation and Usage

1. Clone this repository or copy the files to your local server (e.g., Apache with PHP).  
2. Ensure PHP is configured and the backend PHP files are present (to be implemented as needed).  
3. Open `index.html` in a compatible web browser (Chrome, Firefox, Edge, etc.).  
4. Click the **Rating** button to display the form and start rating.  
5. Click **Close** to hide the form.
